# Make You Mad · 整蛊大冒险

一个纯前端、单文件的整蛊解谜小游戏：**150 关 / 50 种玩法 / 10 种修饰变体**。
每一关都在骗你——提示是反的、按钮会跑、颜色和文字对不上、耐心比手速更重要。

- 在线试玩：<https://1asdfghjkl9.github.io/make-you-mad/>
- 技术栈：原生 HTML + CSS + JavaScript，零依赖、零构建，双击 `index.html` 即可运行
- 适配：手机竖屏优先，支持桌面鼠标；进度保存在浏览器 `localStorage`

## 玩法

1. 打开页面 → 过 5 条「隐私协议」→ 把螺丝拖进齿轮 → 开始。
2. 每关只有一个操作能让它通过，但提示往往在误导你。
3. 每 5 关一个存档点，答错会退回最近存档点。
4. 标题页「选关」可跳到已解锁的关卡；输入兑换码 `1101` 可解锁全部关卡（调试/体验用）。

## 50 种玩法

点击类（按钮/颜色/数学/顺序/连点/填色/配对/找不同/找词/路径/解码/判断题/排序）、
操作类（长按/拖拽/旋转/滑动/双按/平衡/稳定/避障/盲找）、
耐心类（倒计时/等待/掐点/反应/记忆/数数/规律/连锁/轮盘/猜数）……

## 说明

- 关卡由确定性算法生成（同一关每次进去都一样），进度存 `localStorage`：`mym-cp`（存档点）、`mym-max`（最高关）、`mym-cheat`（破解模式）。
- 预留了 `window.Ads` 平台接口 stub（loadingFinished / gameplayStart / interstitial 等），方便接入 Poki、CrazyGames 之类的 H5 游戏平台。
- 这是个「故意让人抓狂」的游戏，玩到一半想砸屏幕属于正常设计。
